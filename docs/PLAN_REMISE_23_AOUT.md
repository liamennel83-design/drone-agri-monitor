## Plan B si le vol ne peut pas être répété

Les images peuvent être acquises avec la caméra maintenue à une hauteur fixe de 0,70 m au-dessus des pots. La procédure doit être décrite comme une acquisition statique pour constituer la base annotée. Elle ne remplace pas un vol autonome, mais elle permet de valider le bloc imagerie sans attendre la navigation complète.
