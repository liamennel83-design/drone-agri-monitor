# Scripts — Outils et Utilitaires

Ce dossier contient les scripts utilitaires pour le projet.

## Fichiers

| Fichier | Description |
|---------|-------------|
| `collecte_images.py` | Collecte et annotation d'images de tomates |

## Utilisation

### Collecte d'images
```bash
# Collecter des images de test
python scripts/collecte_images.py

# Annoter manuellement des images
python scripts/collecte_images.py <dossier_source> <categorie>
```

### Catégories
- `healthy` : Images de tomates saines
- `stressed` : Images de tomates stressées
